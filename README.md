- 🏗️ High-level architecture
- ⚠️ Technical debt hotspots
- 📊 Repository health score
- 🧠 AI-powered codebase insights

## Perfect for

- New engineers onboarding to a project
- Inheriting legacy code
- Technical due diligence
- Open source contributors
- Engineering managers reviewing repositories
